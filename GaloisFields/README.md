# Работа 1. Конечные поля и аффинный шифр

Поле строится как GF(p)[x]/f(x), где p — простое число, f — унитарный неприводимый многочлен степени n. Многочлен задаётся коэффициентами от свободного члена к старшей степени. Например, `1,1,0,1,1,0,0,0,1` означает x⁸+x⁴+x³+x+1. Если `--poly` не указан, программа находит первый подходящий многочлен. Неприводимость проверяется делением на все унитарные многочлены степени до n/2: любой приводимый многочлен имеет такой делитель.

Элемент кодируется целым индексом 0≤v<pⁿ: цифры v по основанию p — коэффициенты многочлена. Сложение выполняется по коэффициентам, умножение — свёртка с приведением по f. Обратный элемент вычисляется как v^(pⁿ−2). Образующие проверяются по простым делителям pⁿ−1.

```powershell
go run ./GaloisFields field --p 3 --n 2
go run ./GaloisFields mul --p 2 --n 8 --poly 1,1,0,1,1,0,0,0,1 --x 87 --y 19
# 254 (0xfe): контрольный пример 0x57 * 0x13
go run ./GaloisFields add --p 3 --n 2 --poly 1,0,1 --x 8 --y 8
# 4
go run ./GaloisFields inv --p 2 --n 8 --poly 1,1,0,1,1,0,0,0,1 --x 83
# 202
go run ./GaloisFields generators --p 3 --n 2
go run ./GaloisFields powers --p 3 --n 2 --x 4
```

`field` показывает параметры, многочлен и элементы, `generators` — все образующие, `powers` — g⁰,…,g^(q−2), `add`, `mul`, `inv` — отдельные операции. Для таблиц используется `--limit` (по умолчанию 32, 0 скрывает элементы); количество элементов/образующих выводится независимо от ограничения отображения. `powers` принимает только образующую.

Аффинный шифр вычисляет y=αx+β; α≠0. Расшифрование вычисляет x=α⁻¹(y−β). Произвольные байты, в том числе UTF-8, кодируются фиксированным числом цифр по основанию q=pⁿ на каждый байт: выбирается минимальное k с q^k≥256. В GF(256) байт соответствует одному элементу. JSON хранит версию 1, параметры поля, длину исходных байтов и массив зашифрованных индексов; ключи α и β передаются отдельно. Проверяются параметры, диапазоны, количество элементов и каноничность восстановленных байтов.

```powershell
go run ./GaloisFields encrypt --p 3 --n 2 --alpha 3 --beta 5 --text 'Привет, мир!' --out cipher.json
go run ./GaloisFields decrypt --p 3 --n 2 --alpha 3 --beta 5 --in cipher.json
# Привет, мир!
go run ./GaloisFields encrypt --p 2 --n 8 --alpha 83 --beta 19 --in input.bin --out bytes.json
go run ./GaloisFields decrypt --p 2 --n 8 --alpha 83 --beta 19 --in bytes.json --out restored.bin
go test ./internal/galois ./GaloisFields
```

`--in` читает файл, иначе используется `--text` (включая пустую строку). `--out` создаёт новый файл без перезаписи; без него результат идёт в stdout. Для расшифрования stdout содержит точные исходные байты без добавленного перевода строки. Повторный запуск примера с тем же выходным файлом требует другого имени либо явного удаления старого файла пользователем.
