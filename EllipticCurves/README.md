# Работа 2. Эллиптические кривые над простым полем

Исследуется E: y²=x³+ax+b mod p. Проверяются простота p>3 и невырожденность 4a³+27b²≠0 mod p. Группа включает бесконечно удалённую точку O. Для разных абсцисс λ=(y₂−y₁)/(x₂−x₁), для удвоения λ=(3x₁²+a)/(2y₁); затем x₃=λ²−x₁−x₂, y₃=λ(x₁−x₃)−y₁. Вертикальные прямые дают O, отрицание меняет знак y. Умножение использует двоичный метод; отрицательные скаляры поддерживаются.

Все координаты и скаляры используют `math/big`. Общая реализация `internal/ec` используется также в работе 4.2. Методы возвращают новые значения и не изменяют аргументы. CLI проверяет принадлежность введённых точек кривой. Точка задаётся `--point x,y`, вторая — `--other x,y`; для O используется `inf`. Числа задаются в десятичной записи.

```powershell
go run ./EllipticCurves info --limit 5
# p=1031, a=1, b=0; точный порядок группы 1032
go run ./EllipticCurves add --p 17 --a 2 --b 2 --point 5,1 --other 5,1
# (6,3)
go run ./EllipticCurves mul --p 17 --a 2 --b 2 --point 5,1 --k 3
# (10,6)
go run ./EllipticCurves mul --p 17 --a 2 --b 2 --point 5,1 --k -1
# (5,16)
go run ./EllipticCurves subgroups --p 17 --a 2 --b 2 --limit 3
# одна циклическая подгруппа простого порядка 19
go run ./EllipticCurves subgroups --p 5 --a 1 --b 0 --limit 4
# три различные подгруппы порядка 2
go test ./internal/ec ./EllipticCurves
```

В примере по умолчанию #E(F₁₀₃₁)=1032, что принадлежит требуемому интервалу [2¹⁰,2⁵¹²]. Порядок найден точным перечислением **всех** точек, включая O, и не подменяется порядком случайной точки. Независимая математическая проверка: 1031≡3 mod 4, поэтому −1 — квадратичный невычет; значения x³+x при x и −x имеют противоположные квадратичные характеры, их вклады в сумму характеров сокращаются и #E=p+1=1032. Для каждого x программа вычисляет правую часть уравнения и находит все y через таблицу квадратов. Полный перебор ограничен p≤4096. При больших p `info` и `subgroups` возвращают ошибку; `add` и `mul` работают с большими параметрами, включая 512-битные простые.

Для поиска всех циклических подгрупп простого порядка факторизуется точный порядок группы. Для каждой точки её порядок получается последовательным удалением простых делителей; умножение точки порядка d на d/ℓ даёт точку порядка ℓ. Группы с одинаковыми элементами объединяются. Это учитывает также нециклические группы, где простое умножение всех точек на #E/ℓ может потерять подгруппы. Каждая группа выводит порядок и образующую; `--limit` ограничивает показ её элементов (по умолчанию 10, 0 скрывает элементы).
